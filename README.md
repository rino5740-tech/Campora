# Campora Agronova — V2

Landing page de agricultura de precisión.

## Instalación
npm install
npm run dev

## Variables
Copia `.env.example` a `.env.local` y configura `NEXT_PUBLIC_WHATSAPP_NUMBER`.

## Logo
El logo proporcionado por el cliente está en `public/logo-campora-agronova.png`.

## Producción
npm run build
npm start
